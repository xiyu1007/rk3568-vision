## 6.1 `muxer.cpp` — 封装（FLV/MP4）

Muxer 是封装器，把 H.264 包封装成 FLV（推流）或 MP4（录制）。RtmpStreamer 和 Mp4Recorder 都复用它。

### 6.1.1 Open（打开封装器）

```cpp
bool Muxer::Open(format, url, width, height, fps, bitrate, extradata, extradata_size, add_silent_audio) {
    fps_ = fps;

    // 1. 分配输出上下文（format="flv"/"mp4", url=rtmp地址/文件路径）
    avformat_alloc_output_context2(&context_, nullptr, format.c_str(), url.c_str());

    // 2. 创建视频流
    video_stream_ = avformat_new_stream(context_, nullptr);
    video_stream_->codecpar->codec_type = AVMEDIA_TYPE_VIDEO;
    video_stream_->codecpar->codec_id   = AV_CODEC_ID_H264;
    video_stream_->codecpar->width/height/bit_rate...
    video_stream_->time_base = {1, fps};          // 时间基 1/fps

    // 3. 复制 SPS/PPS（AVCC 格式）
    if (extradata) {
        video_stream_->codecpar->extradata = av_mallocz(extradata_size + PADDING);
        memcpy(extradata, ...);
        video_stream_->codecpar->extradata_size = extradata_size;
    }

    // 4. FLV 推流补静音 AAC 音轨（mediamtx 需音轨才转发视频）
    if (add_silent_audio) InitializeSilentAudio();

    // 5. 打开输出 + 写头
    avio_open(&context_->pb, url, AVIO_FLAG_WRITE);
    avformat_write_header(context_, nullptr);

    // 6. 若推流地址是回环，补打跨机器拉流地址
    if (url.find("127.0.0.1") != npos) {
        std::string lan_ip = GetLanIp();
        lan_url.replace("127.0.0.1", lan_ip);
        log("拉流地址: %s", lan_url);
    }
}
```

**逐行讲解**：
- `avformat_alloc_output_context2(&ctx, nullptr, "flv", "rtmp://...")`：根据格式名和 URL 分配输出上下文（内部自动选对应的 muxer）。
- `avformat_new_stream`：创建视频流，设 codecpar（编码参数）：H264、宽高、码率、时间基。
- **extradata = SPS/PPS**：把编码器的 SPS/PPS（AVCC 格式）复制到流的 extradata，FLV 解码器初始化需要。
- `InitializeSilentAudio`：FLV 补静音 AAC（下面讲）。
- `avio_open` + `avformat_write_header`：打开输出 + 写 FLV 头。
- `GetLanIp`：`getifaddrs` 取本机非回环 IPv4，推流地址是 127.0.0.1 时补打跨机器拉流地址。

### 6.1.2 Push（写一个 H264 包）

```cpp
bool Muxer::Push(const PacketPtr& packet) {
    AVPacket* temp = av_packet_alloc();
    av_packet_ref(temp, packet.get());      // 引用（浅拷贝，不复制数据）
    temp->stream_index = video_stream_->index;
    av_packet_rescale_ts(temp, {1, fps_}, video_stream_->time_base);   // 时间戳换算
    int ret = av_interleaved_write_frame(context_, temp);   // 交织写
    av_packet_free(&temp);
    if (ret < 0) { warn("write failed"); return false; }
    WriteSilentAudio(packet->pts);          // 补静音音轨
    return true;
}
```

**逐行讲解**：
- `av_packet_ref`：引用（reference），**不复制数据**（两个 AVPacket 共享同一块 buffer），只是引用计数 +1。相比 `av_packet_clone`（深拷贝）高效。
- `av_packet_rescale_ts`：把时间戳从源时间基（1/fps）换算到流的时间基。FLV 的流时间基被 muxer 改成 1/1000（毫秒），这里做了换算。
- `av_interleaved_write_frame`：**按 DTS 交织写**音视频包（内部有缓冲，保证音视频按时间顺序输出）。
- `WriteSilentAudio(packet->pts)`：写静音音频（下面讲）。

### 6.1.3 静音 AAC 音轨（InitializeSilentAudio + WriteSilentAudio）

```cpp
void Muxer::InitializeSilentAudio() {
    audio_stream_ = avformat_new_stream(context_, nullptr);
    audio_stream_->codecpar->codec_type = AVMEDIA_TYPE_AUDIO;
    audio_stream_->codecpar->codec_id   = AV_CODEC_ID_AAC;
    audio_stream_->codecpar->sample_rate = 44100;
    audio_stream_->codecpar->channels    = 1;         // 单声道
    audio_stream_->time_base = {1, 44100};            // 音频时间基 1/44100（采样率）

    // AudioSpecificConfig：AAC-LC / 44100Hz / 单声道（2 字节，硬编码）
    static const uint8_t kAudioSpecificConfig[2] = {0x12, 0x08};
    audio_stream_->codecpar->extradata = ...;
}

void Muxer::WriteSilentAudio(int64_t video_pts) {
    static const uint8_t kSilentAacFrame[4] = {0x01, 0x18, 0x20, 0x07};   // 静音帧（硬编码）

    // 按视频时间戳换算目标音频采样数，每次写 1024 样本直到追上
    const int64_t target = video_pts * 44100 / fps_;
    do {
        AVPacket* packet = av_packet_alloc();
        av_new_packet(packet, 4);
        memcpy(packet->data, kSilentAacFrame, 4);
        packet->stream_index = audio_stream_->index;
        packet->pts = packet->dts = audio_pts_;
        av_packet_rescale_ts(packet, {1, 44100}, audio_stream_->time_base);  // 采样数→毫秒
        audio_pts_ += 1024;                            // AAC-LC 每帧 1024 样本
        av_interleaved_write_frame(context_, packet);
        av_packet_free(&packet);
    } while (audio_pts_ < target);
}
```

**逐行讲解（这是两个重要知识点）**：
1. **为什么补静音 AAC**：mediamtx v1.9.3 有一个行为——**不转发「纯视频、无音频」的 RTMP 流**（拉流端 0 帧）。所以 FLV 要补一路静音 AAC，满足"含音频轨"的要求，mediamtx 才转发视频。静音帧是 **ffmpeg CLI 预生成的硬编码字节**（4 字节 `0x01 0x18 0x20 0x07`），不用板端 AAC 编码器（版本错配会段错误）。
2. **时间戳对齐（关键 bug 修复）**：
   - 音频时间基是 1/44100（采样率），视频是 1/fps。
   - `target = video_pts * 44100 / fps`：把视频时间戳换算成"目标音频采样数"。
   - `do-while` 循环：每次写 1024 个样本（AAC-LC 一帧是 1024 样本），直到追平视频时间戳。保证音频和视频**时间对齐**。
   - **必须 `av_packet_rescale_ts` 换算到毫秒**：FLV muxer 会把音频流 time_base 强制改成 1/1000（毫秒），如果直接把采样数当 pts 写（不换算），音频时间戳会比视频大 ~44 倍，A/V 错位，拉流端长时间缓冲。

**面试点**：为什么要补静音 AAC？音频时间戳为什么必须和视频对齐？FLV 的时间基是多少？

## 6.2 `rtmp_streamer.cpp` — RTMP 推流 + 断线重连

```cpp
bool RtmpStreamer::Push(const PacketPtr& packet) {
    // 未打开时：按配置尝试重连
    if (!muxer_.IsOpen()) {
        if (!config_.reconnect ||
            (config_.max_reconnect >= 0 && reconnect_count_ >= config_.max_reconnect)) {
            return false;                       // 不重连 / 超过最大次数
        }
        if (reconnect_count_ > 0) {
            sleep(reconnect_delay_ms);          // 仅断线重连时才等待（首连不睡）
        }
        if (!Open()) { ++reconnect_count_; return false; }
    }

    if (muxer_.Push(packet)) { reconnect_count_ = 0; return true; }   // 成功清零计数
    muxer_.Close();                            // 写失败则关闭，下次 Push 重连
    return false;
}
```

**逐行讲解**：
- **懒打开**：Muxer 首包时才打开（此时 SPS/PPS extradata 才就绪）。
- **断线重连**：写失败（`muxer_.Push` 返回 false）→ `muxer_.Close()` 关闭 → 下次 Push 检测到未打开 → 等待 `reconnect_delay_ms` 后重连。
- **`reconnect_count_ > 0` 才 sleep**：这是修复过的一个 bug。原来的代码首连也 sleep 2 秒，导致启动白白等 2 秒、编码包堆积、时间戳跳变、拉流端缓冲。
- **`reconnect_count_ = 0`**：推成功就清零重连计数（下次断了重新计）。

## 6.3 `mp4_recorder.cpp` — MP4 录制

```cpp
bool Mp4Recorder::Open(...) {
    return muxer_.Open("mp4", config_.path, width, height, fps, bitrate,
                       extradata, extradata_size, /*add_silent_audio=*/false);
}
bool Mp4Recorder::Push(const PacketPtr& packet) { return muxer_.Push(packet); }
void Mp4Recorder::Close() { muxer_.Close(); }
```

**逐行讲解**：Mp4Recorder 就是一个薄封装，复用 Muxer。区别：格式是 "mp4"（不是 "flv"），`add_silent_audio=false`（MP4 不需要静音音轨），没有断线重连（本地文件写失败就失败）。
