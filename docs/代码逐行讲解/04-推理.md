## 4.1 常量与工具函数

### 4.1.1 YOLOv5 常量

```cpp
constexpr int kNumClasses = 80;     // COCO 80 类
constexpr int kBoxChannels = 85;    // 4 边框 + 1 目标置信度 + 80 类别 = 85
constexpr int kNumAnchors = 3;      // 每个输出头 3 个 anchor

constexpr int kAnchors[3][6] = {
    {10, 13,   16, 30,   33, 23},      // stride 8   小目标
    {30, 61,   62, 45,   59, 119},     // stride 16  中目标
    {116, 90,  156, 198, 373, 326},    // stride 32  大目标
};
```

**逐行讲解**：
- `kBoxChannels = 85`：每个 anchor 预测 85 个值 = **4 个边框（tx,ty,tw,th）+ 1 个目标置信度（objectness）+ 80 个类别分数**。
- `kNumAnchors = 3`：每个网格预测 3 个不同宽高比的框。
- `kAnchors[3][6]`：3 个输出头 × 3 个 anchor × 2 个值（宽、高）。这是 YOLOv5 的**预设 anchor（先验框）**，模型训练时聚类出来的典型目标宽高。stride 8 的头负责小目标（anchor 小），stride 32 负责大目标（anchor 大）。

### 4.1.2 工具函数

```cpp
inline float Sigmoid(float v) { return 1.0f / (1.0f + std::exp(-v)); }
inline uint8_t ClampToUint8(float v) { return v < 0 ? 0 : (v > 255 ? 255 : (uint8_t)v); }
inline float Dequantize(int8_t v, int32_t zp, float scale) {
    return (float(v) - float(zp)) * scale;   // 反量化
}
```

**逐行讲解**：
- `Sigmoid`：把 logits 映射到 (0,1)，常用于目标置信度/边框偏移/类别概率。
- `ClampToUint8`：float 钳制到 [0,255] 转 uint8（颜色值范围）。
- `Dequantize`：**int8 反量化**。`(int8 - zero_point) * scale` 把量化整数还原成 float。

## 4.2 Initialize（加载模型 + 查询 IO）

```cpp
bool Inferencer::Initialize() {
    // 1. 加载 RKNN 模型（size=0 表示 model 参数是文件路径）
    int ret = rknn_init(&context_, const_cast<char*>(config_.model_path.c_str()), 0, 0, nullptr);

    // 2. 查询输入/输出数量
    rknn_input_output_num io_num{};
    rknn_query(context_, RKNN_QUERY_IN_OUT_NUM, &io_num, sizeof(io_num));
    output_count_ = io_num.n_output;

    // 3. 查询输入尺寸（NCHW 或 NHWC 布局）
    rknn_tensor_attr input_attribute{};
    input_attribute.index = 0;
    rknn_query(context_, RKNN_QUERY_INPUT_ATTR, &input_attribute, sizeof(input_attribute));
    if (input_attribute.fmt == RKNN_TENSOR_NCHW) {
        model_height_ = input_attribute.dims[2];
        model_width_  = input_attribute.dims[3];
    } else {   // NHWC
        model_height_ = input_attribute.dims[1];
        model_width_  = input_attribute.dims[2];
    }

    // 4. 查询输出属性（拿到 scale/zp 反量化参数）并分配缓冲
    QueryOutputs();

    // 5. 加载标签
    std::ifstream label_file(config_.labels_path);
    while (std::getline(label_file, line)) labels_.push_back(line);

    rgb_buffer_.resize(model_width_ * model_height_ * 3);   // 模型输入 RGB 缓冲
    initialized_ = true;
}
```

**逐行讲解**：
- `rknn_init(&ctx, path, 0, 0, nullptr)`：加载 .rknn 模型，`context_` 是 RKNN 上下文（后续所有操作都用它）。
- `rknn_query(RKNN_QUERY_IN_OUT_NUM)`：查模型有几个输入几个输出。
- `rknn_query(RKNN_QUERY_INPUT_ATTR)`：查输入的尺寸和布局。**NCHW vs NHWC** 是两种张量内存布局——NCHW 是 [批,通道,高,宽]，NHWC 是 [批,高,宽,通道]。代码根据 `fmt` 字段判断，从不同 dims 位置取宽高。
- `QueryOutputs()`：查每个输出的 scale/zp（反量化参数）。
- 标签加载：`labels_path` 文件每行一个类别名（"person"、"car"...）。

### 4.2.1 QueryOutputs（查输出属性）

```cpp
bool Inferencer::QueryOutputs() {
    output_attributes_.resize(output_count_);
    output_offsets_.resize(output_count_);
    size_t total_elements = 0;
    for (uint32_t i = 0; i < output_count_; ++i) {
        output_attributes_[i].index = i;
        rknn_query(context_, RKNN_QUERY_OUTPUT_ATTR, &output_attributes_[i], ...);

        int elements = 1;
        for (uint32_t d = 0; d < output_attributes_[i].n_dims; ++d)
            elements *= output_attributes_[i].dims[d];   // 各维相乘 = 总元素数

        output_offsets_[i] = total_elements;   // 记录这个输出在反量化缓冲里的起始偏移
        total_elements += elements;
        // 打印 scale（缩放系数）和 zp（零点）
    }
    dequant_buffer_.resize(total_elements);   // 一次性分配所有输出的反量化缓冲
    return true;
}
```

**逐行讲解**：
- YOLOv5 有 **3 个输出**（stride 8/16/32），每个输出的形状不同。
- `elements` 是各维相乘（如 1×3×80×80×85），是该输出的总元素数。
- `output_offsets_`：把 3 个输出的数据**拼进一个连续缓冲** `dequant_buffer_`，避免多次分配。
- `scale` 和 `zp` 是量化参数，**从模型元数据里查出来的**，反量化时用。

## 4.3 Preprocess（RGA 硬件前处理 + letterbox）

```cpp
void Inferencer::Preprocess(const FramePtr& frame, uint8_t* rgb, LetterboxInfo& letterbox) {
    const int width = frame->width, height = frame->height;

    // 1. 计算 letterbox 缩放参数
    const float scale = std::min((float)model_width_/width, (float)model_height_/height);
    const int scaled_width  = (int)(width * scale);    // 等比缩放后的宽
    const int scaled_height = (int)(height * scale);
    letterbox.scale = scale;
    letterbox.pad_x = (model_width_  - scaled_width)  / 2;   // 水平灰边
    letterbox.pad_y = (model_height_ - scaled_height) / 2;   // 垂直灰边

    // 2. 灰边填充（YOLOv5 惯例 114）
    std::memset(rgb, 114, model_width_ * model_height_ * 3);

    // 3. RGA：NV12 → RGB 格式转换 + 等比缩放
    //    源按数据来源分流：V4L2(dmabuf) 走 wrapbuffer_fd，mp4(CPU 内存) 走 wrapbuffer_virtualaddr
    rga_buffer_t src;
    if (!frame->dma_fds.empty()) {
        src = wrapbuffer_fd(frame->dma_fds[0], width, height,
                            RK_FORMAT_YCbCr_420_SP, frame->nv12_stride, height);
    } else {
        src = wrapbuffer_virtualaddr(const_cast<uint8_t*>(frame->nv12_data), width, height,
                                     RK_FORMAT_YCbCr_420_SP, frame->nv12_stride, height);
    }
    rga_buffer_t dst = wrapbuffer_virtualaddr(
        rgb_tmp_buffer_.data(), scaled_width, scaled_height,
        RK_FORMAT_RGB_888, scaled_width, scaled_height);

    const IM_STATUS status = imresize(src, dst);   // RGA 硬件转换+缩放，同步执行
    if (status == IM_STATUS_SUCCESS) {
        // 把缩放后的 RGB 拷到 letterbox 的居中位置
        for (int row = 0; row < scaled_height; ++row) {
            memcpy(rgb + (row + pad_y)*model_width_*3 + pad_x*3,
                   rgb_tmp + row*scaled_width*3, scaled_width*3);
        }
        return;
    }
    // RGA 失败兜底：CPU 浮点转换（后面代码，功能保证）
    ...
}
```

**逐行讲解**：
- **letterbox 缩放**：`scale = min(640/w, 640/h)` 取**较小的比例**，保证整图等比缩放进 640×640（不变形），短边留灰边。`pad_x/pad_y` 是灰边宽度，让缩放后的图**居中**。
- **灰边填充 114**：YOLOv5 训练时用的灰边像素值是 114（所以推理也要用 114）。
- **wrapbuffer_* 参数顺序**（注释反复强调）：`addr/fd, width, height, format, wstride, hstride`。容易记错，是高频坑。
- `RK_FORMAT_YCbCr_420_SP` = NV12（Y + 交错 UV），`RK_FORMAT_RGB_888` = RGB。
- **imresize 同步执行**：RGA 硬件做 NV12→RGB 转换 + 缩放，一次完成两件事，从 CPU ~50ms 降到 ~3ms。
- **为什么 V4L2 走 fd、mp4 走虚拟地址**：V4L2 采集的是 dma-coherent DMA buffer，必须用 `wrapbuffer_fd` 走 dma-buf 零拷贝共享；若用 `wrapbuffer_virtualaddr`，RGA2 会尝试用自己的 MMU 重映射这段 dma-coherent 内存，IOMMU 翻译失败返回 -EINVAL（日志 "RGA_BLIT fail: Invalid argument"），前处理回退 CPU。mp4 解码出来是普通 CPU 内存（无 fd），才用 `wrapbuffer_virtualaddr`；目标 `rgb_tmp_buffer_` 也是 CPU 内存，用虚拟地址。
- **RGA 失败兜底**：CPU 浮点 NV12→RGB 转换（后面省略的代码），保证 RGA 挂了功能也不坏。兜底里用了 YUV→RGB 转换公式（`R = 1.164*(Y-16) + 1.596*(V-128)` 等）。

**面试点**：letterbox 是什么？为什么灰边用 114？RGA 做了什么？

## 4.4 Detect（完整推理，主函数）

### 4.4.1 设置输入 + 推理

```cpp
bool Inferencer::Detect(const FramePtr& frame) {
    // 1. 前处理
    LetterboxInfo letterbox;
    Preprocess(frame, rgb_buffer_.data(), letterbox);

    // 2. 设置输入 + 推理
    rknn_input input{};
    input.index = 0;
    input.type  = RKNN_TENSOR_UINT8;   // 输入类型 uint8
    input.fmt   = RKNN_TENSOR_NHWC;    // 输入布局 NHWC（高宽通道）
    input.buf   = rgb_buffer_.data();
    input.size  = rgb_buffer_.size();
    rknn_inputs_set(context_, 1, &input);
    rknn_run(context_, nullptr);        // NPU 推理

    // 3. 取输出（INT8）
    std::vector<rknn_output> outputs(output_count_);
    for (uint32_t i = 0; i < output_count_; ++i) {
        outputs[i].index = i;
        outputs[i].want_float = 0;      // 要 int8（不要 float）
        outputs[i].is_prealloc = 0;
    }
    rknn_outputs_get(context_, output_count_, outputs.data(), nullptr);
```

**逐行讲解**：
- `RKNN_TENSOR_UINT8` + `RKNN_TENSOR_NHWC`：输入是 uint8 的 RGB，NHWC 布局（[1, 640, 640, 3]）。
- `rknn_run`：真正在 NPU 上推理（同步执行）。
- `rknn_outputs_get`：取输出。`want_float=0` 表示要 **int8 原始输出**（不是反量化后的 float），自己用 NEON 反量化（更快、更可控）。

### 4.4.2 NEON 反量化

```cpp
#if defined(__aarch64__) || defined(__ARM_NEON)
#include <arm_neon.h>
#endif

// 反量化循环
const float32x4_t zp_v = vdupq_n_f32(zero_point);   // 4 个零点
const float32x4_t scale_v = vdupq_n_f32(scale);     // 4 个 scale
int e = 0;
for (; e + 16 <= elements; e += 16) {               // 一次处理 16 个 int8
    const int8x16_t v8 = vld1q_s8(src + e);          // 加载 16 个 int8
    const int16x8_t v16_low  = vmovl_s8(vget_low_s8(v8));   // 扩到 int16
    const int16x8_t v16_high = vmovl_s8(vget_high_s8(v8));
    const int32x4_t v32_0 = vmovl_s16(vget_low_s16(v16_low));  // 扩到 int32
    ... // 4 个 int32x4
    float32x4_t f0 = vcvtq_f32_s32(v32_0);           // int32 → float
    f0 = vmulq_f32(vsubq_f32(f0, zp_v), scale_v);    // (v - zp) * scale
    vst1q_f32(dst + e, f0);                          // 存回
}
for (; e < elements; ++e) dst[e] = Dequantize(src[e], zp, scale);  // 剩余标量处理
#else
for (int e = 0; e < elements; ++e) dst[e] = Dequantize(src[e], zp, scale);
#endif
```

**逐行讲解**：
- **NEON 是 ARM 的 SIMD 指令集**，128 位寄存器，一次算 4 个 float 或 16 个 int8。
- 反量化流程：`int8 → int16 → int32 → float → (float - zp) * scale`。
- `vld1q_s8` 一次加载 16 个 int8；`vmovl_s8` 把 int8 扩成 int16；`vcvtq_f32_s32` 把 int32 转 float；`vsubq_f32` 减 zp、`vmulq_f32` 乘 scale；`vst1q_f32` 存回。
- 主循环 `e += 16` 处理 16 的倍数，剩余不足 16 的用标量循环兜底。
- `#if defined(__aarch64__)`：NEON 代码只在 ARM 上编译，x86 走标量循环（x86 只是编译检查）。

**面试点**：为什么反量化要用 NEON？反量化是逐元素的简单运算（`(v-zp)*scale`），SIMD 能一次算 16 个，是纯计算密集型，非常适合向量化。这是性能优化的重要手段。

### 4.4.3 YOLOv5 解码（3 个输出头 + anchor）

```cpp
for (size_t o = 0; o < tensors.size() && o < 3; ++o) {
    const OutputTensor& tensor = tensors[o];
    const int grid_len = tensor.height * tensor.width;   // 网格总数（如 80×80）
    const int anchor_row = (tensor.stride == 8) ? 0 : (tensor.stride == 16) ? 1 : 2;

    for (int a = 0; a < kNumAnchors; ++a) {
        const int base = kBoxChannels * a;   // 第 a 个 anchor 的通道基址（0/85/170）
        for (int gy = 0; gy < tensor.height; ++gy)
            for (int gx = 0; gx < tensor.width; ++gx) {
                const int idx = gy * tensor.width + gx;     // 网格索引
                const int off = base * grid_len + idx;      // NCHW 数据基偏移

                float objectness = tensor.data[off + 4 * grid_len];   // 目标置信度
                if (config_.use_sigmoid) objectness = Sigmoid(objectness);
                if (objectness < config_.confidence_threshold) continue;   // 目标阈值过滤

                // 找最大类别分数
                int max_class = 0;
                float max_class_score = tensor.data[off + 5 * grid_len];
                for (int c = 1; c < kNumClasses; ++c) {
                    float v = tensor.data[off + (5 + c) * grid_len];
                    if (v > max_class_score) { max_class_score = v; max_class = c; }
                }
                if (config_.use_sigmoid) max_class_score = Sigmoid(max_class_score);
                const float score = objectness * max_class_score;   // 最终分数
                if (score < confidence_threshold) continue;

                // 边框解码
                float tx = tensor.data[off + 0 * grid_len];
                ... ty, tw, th ...
                if (config_.use_sigmoid) { tx=Sigmoid(tx); ty=Sigmoid(ty); tw=Sigmoid(tw); th=Sigmoid(th); }
                const float bx = (tx * 2.0f - 0.5f + gx) * tensor.stride;
                const float by = (ty * 2.0f - 0.5f + gy) * tensor.stride;
                const float bw = std::pow(tw * 2.0f, 2) * kAnchors[anchor_row][2*a];
                const float bh = std::pow(th * 2.0f, 2) * kAnchors[anchor_row][2*a+1];

                // 模型坐标(640×640) → 原图坐标：减 padding 除 scale
                candidates.push_back({
                    (bx - bw*0.5f - letterbox.pad_x) / letterbox.scale,
                    (by - bh*0.5f - letterbox.pad_y) / letterbox.scale,
                    bw / letterbox.scale, bh / letterbox.scale,
                    score, max_class});
            }
    }
}
```

**逐行讲解（这是 YOLOv5 后处理的核心，要理解透彻）**：
- **3 个输出头**：stride 8 的输出是 80×80 网格（小目标），stride 16 是 40×40（中目标），stride 32 是 20×20（大目标）。
- **数据布局（NCHW）**：每个输出张量形状是 `[1, 255, grid_h, grid_w]`（255 = 3 anchor × 85 通道）。`off = base * grid_len + idx` 是"第 a 个 anchor、第 idx 个网格"的数据起始位置。`+ 4 * grid_len` 是第 4 个通道（objectness），`+ (5+c) * grid_len` 是第 c 个类别分数。**理解这个偏移是理解 YOLOv5 后处理的关键**。
- **objectness 阈值**：先过滤目标置信度低的（大部分网格没有目标）。
- **类别分数**：找 80 个类别里分数最高的，`score = objectness × max_class_score`。
- **use_sigmoid**：标准 yolov5s 输出 logits（要 sigmoid），relu/n 版输出已是 sigmoid 后值（不要再 sigmoid）。**换模型必须同步改**，否则阈值失效。
- **边框解码公式**：`bx = (sigmoid(tx)*2 - 0.5 + gx) * stride`。这是 YOLOv5 特有的——sigmoid(tx) 在 (0,1)，`*2-0.5` 映射到 (-0.5, 1.5)，加上网格索引 gx，再乘 stride，就把预测值限制在网格附近的 ±1.5 个网格内。`bw = pow(sigmoid(tw)*2, 2) * anchor_w` 是宽（预测相对 anchor 的缩放，平方保证非负）。
- **坐标逆映射**：模型输出是 640×640 坐标系的，`(bx - bw/2 - pad_x) / scale` 还原到原图坐标（减 padding 再除 scale）。

**面试点**：anchor 是什么？stride 是什么？边框解码公式怎么来的？letterbox 坐标怎么还原？

### 4.4.4 NMS（非极大值抑制）

```cpp
std::vector<char> keep(candidates.size(), 1);   // 标记保留
for (size_t i = 0; i < candidates.size(); ++i) {
    if (!keep[i]) continue;
    for (size_t j = i + 1; j < candidates.size(); ++j) {
        if (!keep[j] || candidates[i].class_id != candidates[j].class_id) continue;
        if (BoxIoU(candidates[i], candidates[j]) > nms_threshold) {
            keep[j] = 0;   // 同类别且 IoU 高，抑制掉
        }
    }
}
```

**逐行讲解**：
- **NMS 的作用**：同一个目标可能被多个框检测到（重叠），NMS 只保留分数最高的那个，抑制重叠的。
- **BoxIoU**：交并比 = 交集面积 / 并集面积，衡量两个框重叠程度。
- 这是**朴素 O(n²) NMS**：两两比较，同类别且 IoU > 阈值就抑制掉分数低的。n 很小（候选框少），O(n²) 够用。

## 4.5 DrawBoxesOnNv12（画框）

```cpp
void DrawBoxesOnNv12(uint8_t* nv12, int width, int height, int nv12_stride,
                     const DetectResult& detection) {
    uint8_t* y_plane = nv12;
    for (uint32_t i = 0; i < detection.count; ++i) {
        const DetectBox& box = detection.boxes[i];
        // 钳制坐标到图像范围
        const int x0 = max(0, min(box.x, width-1));
        ...
        // 画上下两条水平边（把 Y 值设为 255 = 白）
        for (int x = x0; x <= x1; ++x) {
            y_plane[y0 * nv12_stride + x] = 255;
            y_plane[y1 * nv12_stride + x] = 255;
        }
        // 画左右两条垂直边
        for (int y = y0; y <= y1; ++y) {
            y_plane[y * nv12_stride + x0] = 255;
            y_plane[y * nv12_stride + x1] = 255;
        }
    }
}
```

**逐行讲解**：
- 直接在 NV12 的 **Y 平面**（亮度）上画框，把边框像素的 Y 值设为 255（白色）。**只改 Y 不改 UV**，所以框是白/黑色（无色相）。
- `nv12_stride` 是行跨度，访问 `y * stride + x` 定位像素。
- 这是**就地修改**（原地画框），编码线程在编码前调用。

**面试点**：为什么画框只改 Y 平面？因为 Y 是亮度，改成 255 就是白色，不用动 UV（色度），简单高效。
